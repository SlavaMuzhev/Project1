# Проект1

## Описание:
Это виджет для личного кабинета, который показывает несколько последних 
успешных банковских операций клиента.

## Стадия разработки

Проект находттся в стадии разработки. В директории src создаются модули с добавлением новых функций

## Основные модули 

* Модуль **masks** содержит функции для маскировки номера счета и номера карты:

1. Функция *get_mask_card_number* маскирует номер банковской карты в формате: XXXX XX** **** XXXX

2. Функция *get_mask_account* маскирует номер счета в формате: **XXXX

* Модуль **widget** содержит функции для приема и маскировки номера счета и номера карты, 
используя при этом импортируемые функции из модуля **masks**:

1. Функция *mask_account_card* маскирует номер счета в формате: Счет **4305

2. Функция *get_date* возвращает дату в формате 'ДД.ММ.ГГГГ'

* Модуль **processing** содержит функции для сортировки банковских операций:

1. Функция *filter_by_state* фильтрует список операций по статусу выполнения

2. Функция *sort_by_date* сортирует список операций по дате выполнения
