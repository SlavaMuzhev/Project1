# Проект1

## Описание:
Это виджет для личного кабинета, который показывает несколько последних 
успешных банковских операций клиента.

## Стадия разработки

Проект находится в стадии разработки. В директории **src** создаются модули с добавлением новых функций

### Основные модули 

* Модуль **masks** содержит функции для маскировки номера счета и номера карты:

1. Функция *get_mask_card_number* маскирует номер банковской карты в формате: XXXX XX** **** XXXX

2. Функция *get_mask_account* маскирует номер счета в формате: **XXXX

* Модуль **widget** содержит функции для приема и маскировки номера счета и номера карты, 
используя при этом импортируемые функции из модуля **masks**:

1. Функция *mask_account_card* маскирует номер счета в формате: Счет **4305

2. Функция *get_date* возвращает дату в формате 'ДД.ММ.ГГГГ'

* Модуль **processing** содержит функции для сортировки банковских операций:

1. Функция *filter_by_state* фильтрует список операций по статусу выполнения

2. Функция *sort_by_date* сортирует список операций по дате выполнения

* Модуль **generators** содержит функции, реализующие генераторы для обработки данных.

1. Функция *filter_by_currency* возвращает итератор, который поочередно выдает транзакции, 
где валюта операции соответствует заданной.
2. Генератор *transaction_descriptions*, который принимает список словарей с транзакциями 
и возвращает описание каждой операции по очереди
3. Генератор *card_number_generator*, который выдает номера банковских карт
в в формате XXXX XXXX XXXX XXXX

* Модуль **decorators** содержит декораторы.

1. Декоратор log, который будет автоматически логировать начало и конец выполнения функции, 
время работы, а также ее результаты или возникшие ошибки.

* Модуль **utils** содержит функции:

1. Функция *get_transactions_data*, которая принимает на вход путь до JSON-файла 
и возвращает список словарей с данными о финансовых транзакциях. Файл с данными о финансовых 
транзакциях operations.json находится в директорию data/ в корне проекта.

* Модуль **external_api** содержит функции:

1. Функция *get_transaction_amount*, которая принимает на вход транзакцию и возвращает сумму 
транзакции в рублях. Если транзакция была в USD или EUR, происходит обращение к 
внешнему API для получения текущего курса валют и конвертации суммы операции в рубли.

* Модуль **transaction_loader** содержит функции:

1. Функция *reading_transactions_from_csv* для считывания финансовых операций из CSV.
Выдает список словарей с транзакциями.
2. Функция *reading_transactions_from_excel* для считывания финансовых операций из Excel.
Выдает список словарей с транзакциями.

* Модуль **bank_operations** содержит функции:

1. Функция *process_bank_search* принимает список словарей с данными о банковских операциях 
и строку поиска, а возвращает список словарей, у которых в описании есть данная строка.
2. Функцию *process_bank_operations* принимает список словарей с данными о банковских операциях и список категорий операций, 
а возвращает словарь, в котором ключи это названия категорий, значения это количество операций 
в каждой категории.

* Модуль **main** содержит функции:

1. Функция *main* отвечает за основную логику проекта и связывает функциональности между собой


## Установка

1. Клонируйте репозиторий:

`git clone git@github.com:SlavaMuzhev/Project1.git`

2. Перейдите в папку проекта:

`cd C:\Users\........\Project_1>`

3. Установка зависимостей:

`pip install -r requirements.txt`

## Зависимости
* Python 3.x
* Библиотеки, которые указаны в requirements.txt

## Тестирование
Для тестирования используется библиотека **pytest**

Тестами покрываются все функции, находящиеся в модулях из пакета src

Установка pytest:

`poetry add --group dev pytest`

Запуск pytest удобнее всего производить из PyCharm. 
Для этого выполните следующие шаги:
1. Откройте окно Edit Configurations
2. Нажмите на "+" для создания новой конфигурации и выберите pytest
3. Укажите директорию с тестами и директорию проекта в целом

В pytest для анализа покрытия кода надо поставить библиотеку 
**pytest-cov**

Через poetry с добавлением в отдельную группу:

`poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:

`pytest --cov`  — при активированном виртуальном окружении.
